## Description:

A web-based Hangman game built with Python (Flask), HTML, CSS, and JavaScript.  
This project features sound effects, mobile responsiveness, and is deployable online via Render.

## Technology:

Project is created with:

- HTML.
- CSS.
- JavaScript.
- Node.js
- React.js
- mongodb

## Installation

To run this project, use :

```
npm install

```

## Usage

After installing packages, Run cd backend then npm start and in different terminal Run frontend then npm start:

```

npm start 

```
A Link will pop up, Click that for using.
